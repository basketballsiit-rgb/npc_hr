# NPC HR - ระบบบริหารจัดการบุคลากรและเอกสารทางราชการ
**วิทยาลัยสารพัดช่างน่าน (Nan Polytechnic College)**

ระบบเว็บแอปพลิเคชันสำหรับบริหารจัดการข้อมูลบุคลากร การลงเวลาปฏิบัติงาน การขออนุมัติลา และการขออนุมัติเดินทางไปราชการพร้อมสัญญายืมเงินและเคลียร์เงินยืมทางราชการแบบครบวงจร ออกแบบมาเพื่อให้สอดคล้องกับระเบียบการเบิกจ่ายและเอกสารมาตรฐานของหน่วยงานภาครัฐของไทย

---

## 🌟 คุณสมบัติเด่นของระบบ (Key Features)

### 1. ระบบบันทึกเวลาและยื่นใบลา (Attendance & Leave System)
* **ลงเวลาทำงาน**: บันทึกเวลาเข้า-ออกงานของบุคลากรประจำวัน
* **ขออนุมัติการลา**: รองรับการลาป่วย ลากิจ ลาพักผ่อน และอื่นๆ
* **คำนวณวันลาอัจฉริยะ**: คำนวณวันลาจริงโดยหักวันหยุดเสาร์-อาทิตย์ วันหยุดนักขัตฤกษ์ วันหยุดชดเชย และวันปฏิบัติงานพิเศษของวิทยาลัยโดยอัตโนมัติ
* **พิมพ์ใบลามาตรฐาน**: ส่งออกใบลาในรูปแบบ PDF/กระดาษ A4 ตามฟอร์มมาตรฐานงานสารบรรณภาครัฐ (ฟอนต์ TH Sarabun New/PSK ขนาด 16pt)

### 2. ระบบขออนุมัติเดินทางไปราชการ (Travel Request System)
* **ยื่นคำขออนุมัติ**: บันทึกข้อมูลการไปราชการ รายละเอียดผู้เดินทาง วันเดินทาง และสถานที่ปลายทาง
* **ประมาณการค่าใช้จ่าย**: คำนวณเบี้ยเลี้ยง ที่พัก และค่าพาหนะเชื้อเพลิงตามจริงรายบุคคล
* **ส่งออกเอกสาร**: จัดพิมพ์บันทึกข้อความขออนุมัติ (หน้า 1) และใบประมาณการค่าใช้จ่ายเดินทาง (หน้า 2) ได้ทันที

### 3. ระบบสัญญายืมเงินราชการ (Loan Contract System)
* **ออกสัญญายืมเงิน**: เชื่อมโยงข้อมูลประมาณการค่าใช้จ่ายมาจัดทำสัญญายืมเงิน (หน้า 3) อัตโนมัติ
* **ระเบียบคลังที่ถูกต้อง**: จัดรูปเล่มล้อมกรอบชนขอบกระดาษ, ตัวเลขฟอนต์ TH Sarabun พิมพ์ตรงสเกล, มีการแปลงตัวเลขรวมเป็นตัวอักษรภาษาไทยอย่างถูกต้อง และระบบคำนวณวันครบกำหนดคืนเงินยืมคลังให้อัตโนมัติ

### 4. ระบบรายงานผลและเคลียร์เงินยืม (Travel Report & Loan Clearance)
* **รายงานผล**: ส่งรายงานสรุปผลการเดินทางและปฏิบัติงานหลังจากกลับจากราชการ
* **เคลียร์เงินยืม**: ทำรายการชำระคืนเงินยืม/เบิกเพิ่ม ตรวจสอบเปรียบเทียบวงเงินยืมและยอดค่าใช้จ่ายจริง
* **พิมพ์ใบเคลียร์**: ส่งออกใบรายงานการส่งใช้เงินยืมและใบรับเงินฝากเพื่อยื่นต่อฝ่ายการเงิน

### 5. การแจ้งเตือนผ่าน LINE Bot (LINE Notification Integration)
* **แจ้งเตือนทันที**: ส่งข้อความแจ้งเตือนผลการอนุมัติเอกสารและคำขอต่างๆ ไปยังกลุ่มไลน์บุคลากรหรือไลน์ส่วนตัว
* **Deep-Link Auto-Login**: รองรับการคลิกจากไลน์แล้วเข้าสู่ระบบอัตโนมัติ เพื่ออำนวยความสะดวกในการกดรับทราบหรืออนุมัติเอกสารผ่านบราวเซอร์ของแอป LINE

## 🛠️ เทคโนโลยีที่เลือกใช้ (Technology Stack)

* **Frontend**: HTML5, Vanilla CSS, JavaScript (ES6+), SweetAlert2
* **Backend**: Node.js, Express.js
* **Database**: MySQL / MariaDB (ระบบจัดการคิวรีเชื่อมโยงข้อมูลบุคลากรภายนอก APR/SRS)
* **Process Manager**: PM2 (สำหรับรันและควบคุมการทำงานหลังบ้านบนเซิร์ฟเวอร์)
* **Deployment**: GitHub Actions (CI/CD Automated Deployment via SSH)

## 🚀 การติดตั้งและรันระบบเครื่องโลคอล (Local Setup)

### 1. การตั้งค่าฝั่งฐานข้อมูล
1. สร้างฐานข้อมูลชื่อ `eleve_db` ใน MySQL ของคุณ
2. นำเข้าตารางและการตั้งค่าเริ่มต้นโดยรันระบบหลังบ้านเป็นครั้งแรก ระบบจะทำการสร้างตาราง (`users`, `travel_data`, `leave_data`, `attendance` ฯลฯ) ให้อัตโนมัติ

### 2. การรันหลังบ้าน (Backend Server)
1. เข้าไปที่โฟลเดอร์หลังบ้าน:
   ```bash
   cd backend
   ```
2. คัดลอกและสร้างไฟล์คอนฟิกูเรชัน `.env`:
   ```bash
   # ตัวอย่างไฟล์ .env
   PORT=5000
   DB_HOST=localhost
   DB_USER=root
   DB_PASS=
   DB_NAME=eleve_db
   JWT_SECRET=your_secret_key_here
   LINE_ACCESS_TOKEN=your_line_bot_token
   LINE_CHANNEL_SECRET=your_line_channel_secret
   ```
3. ติดตั้ง Dependencies และรันเซิร์ฟเวอร์:
   ```bash
   npm install
   npm start
   ```

### 3. การรันหน้าบ้าน (Frontend Client)
* รันโปรเจกต์ผ่านเว็บบราวเซอร์โดยเรียกหน้าไฟล์ `index.html` หรือรันผ่าน XAMPP เว็บเซิร์ฟเวอร์ที่พาธเครื่องท้องถิ่น เช่น `http://localhost/npc_eleve/`

## 🖨️ มาตรฐานสัดส่วนและการพิมพ์เอกสาร (Printing Guidelines)

* **ความเข้ากันได้ของฟอนต์ (Web Fonts)**: ตัวระบบได้ทำการฝังระบบ Web Font ดึงจากเซิร์ฟเวอร์โดยตรง ทำให้เครื่องลูกข่ายที่ไม่มีฟอนต์ `TH Sarabun New` หรือ `TH Sarabun PSK` ติดตั้งอยู่ในเครื่อง สามารถพิมพ์และบันทึกเอกสารเป็น PDF ด้วยสัดส่วนฟอนต์ของข้าราชการที่ถูกต้องแม่นยำ ไม่หลุดกรอบ A4
* **การสั่งพิมพ์**: เพื่อผลลัพธ์การจัดเลย์เอาต์ที่ดีที่สุด:
  1. ให้เปิดด้วยเว็บบราวเซอร์ Google Chrome หรือ Microsoft Edge
  2. ตรวจสอบการตั้งค่า **มาตราส่วน (Scale)** เป็น **"เริ่มต้น (Default)"**
  3. เลือกขนาดกระดาษเป็น **"A4"** และแนวตั้ง **"Portrait"**
  4. ทำเครื่องหมายถูกที่ช่อง **"กราฟิกพื้นหลัง (Background graphics)"** เสมอ
